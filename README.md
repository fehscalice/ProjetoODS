# ♻️ Recicla+

## Objetivo do Projeto

O **Recicla+** é uma página web desenvolvida para conscientizar e
incentivar práticas sustentáveis, com foco na **reciclagem responsável**
e na educação ambiental. O projeto busca promover o engajamento
comunitário, alinhando tecnologia e sustentabilidade para informar e
inspirar mudanças de hábitos.

Este projeto foi desenvolvido como parte da disciplina **Programação Web
Front-End (HTML & CSS)** da **UTFPR**.

## Conexão com os ODS (ONU)

O projeto está diretamente alinhado ao *ODS 12 -- Consumo e Produção
Responsáveis*, incentivando o descarte correto de resíduos e a promoção
da reciclagem. Também se relaciona ao *ODS 11 -- Cidades e Comunidades
Sustentáveis*, ao incentivar ações locais de impacto ambiental
positivo.

## Estrutura do Site

### Página Principal (`index.html`)

Contém informações educativas sobre: - O que é o projeto **Recicla+** -
Reciclagem responsável - Coleta seletiva - Guia de separação (papel,
plástico, vidro e metal) - Conexão com os ODS da ONU

Inclui: - Cabeçalho e menu de navegação\
- Imagens ilustrativas\
- Ícones (Font Awesome)\
- Rodapé com links para currículos dos autores

### Página de Login (`login.html`)

-   Formulário de autenticação com **e-mail e senha**
-   Link para redirecionamento à página de cadastro

### Página de Cadastro (`register.html`)

-   Formulário com **5 campos obrigatórios**:
    -   Nome completo\
    -   Email\
    -   Senha\
    -   Telefone\
    -   Cidade\
-   Botão que redireciona à página de login
